# UrbanForge — project context

Browser GIS/CAD urban-planning studio (React + TS). Frontend-only so far; data lives in the user's browser (IndexedDB). README.md has full detail. Keep this file short and update it at the end of each phase.

## Commands
- `npm run dev` (port 5173; use `--port 5317 --strictPort` when testing) · `npm test` (Vitest, 413 tests) · backend: `docker compose up -d`, `docker compose run --rm api python -m pytest -q` (plain `pytest` can't import `app`) · `npm run build` (tsc + vite) · `npm run preview`
- Type-check fast: `npx tsc`

## Stack
Vite 8, React 19, TS 7 (tsgo), Tailwind 4, MapLibre GL 6, Terra Draw (draw/edit), Turf 7, Zustand 5 + zundo (undo), idb-keyval, Three.js 0.186 (3D, lazy-loaded), lucide-react (icons — use these, not Unicode glyphs), togeojson/fflate/shpjs/shp-write/dxf-parser (formats, lazy-loaded). Vitest (jsdom only in formats.test.ts).

## Architecture (src/)
- `model.ts` types, component catalogue, ZONING, ROAD_CLASSES, NETWORKS, GENERIC_RULESET, `colorOf`, `defaultAttrs`
- `geo.ts` pure geometry: local metric `frame()`, footprints, subdivide, split/merge plots, splitByLine, snapping, stats
- `roads.ts` roundabouts, cul-de-sacs, junctions, plots along curved roads, measured frontage · `curveRoad` rounded corners: a curved road keeps its bend points in `attrs.pi` (JSON) + `attrs.curveRadius`, geometry = the curve (so every consumer sees it); store `designLine`/`setRoadLine`/`moveRoadPoint` (junction: every road point within 1 m moves)/`splitRoad`/`joinRoads`; MapCanvas edits a road's design line, not its geometry
- `sitecheck.ts` site survey (`surveySite`/`surveyOf`): conflicts with project plots/roads/buildings/parks or OSM development (Overpass; unreachable = blocked, never "clear"), plus roads within `REACH` 500 m and buildings to keep. Wizard offers "Plan around existing development": `generatePlan(…, existing)` keeps plots clear of existing roads/buildings, links spine ends to the nearest existing road, joins street ends to them; accepted plans add the OSM roads/buildings as `status: 'existing'`, clipped to the site + `REACH` (Overpass returns whole ways: a kept road/river was 23 km). If Overpass fails, the wizard offers an explicit "Generate without the OpenStreetMap check" (project-only survey, `surveySite(…, checkOsm=false)`). Water (OSM lakes incl. multipolygon relations via `formats.ts` `joinRings`, river/canal/stream corridors, project `lake`s) is never a conflict and never developed: zones/parks exclude it, plots keep 10 m back, spine/links/cross streets cross it as `structure: 'bridge'` (≤ 300 m), other streets stop at the bank
- `masterplan.ts` street network: cross street on every band cut (through the spine), each side of the spine subdivided on a grid anchored to the spine edge (`subdivide` `origin`/`startY`), then `roads.ts` `connectEnds` joins stubs; tested for connectivity
- `utilities.ts` "Lay pipes" (toolbar + wizard `layPipes`): water main +2 m / sewer −1.5 m along every `buildRoadGraph` edge, junction to junction (so networks connect), hydrant / manhole closing each dead-end street (no open ends), tank + treatment plant if missing; loaded via dynamic `import()` (drive.ts pulls in three) · `pipeflow.ts` flow model: water away from sources, sewage to the plant (Dijkstra), water 1.2 m deep, sewers ≥1.5 m cover falling ≥1:200, manholes; illustrative speeds (hydraulics plugs in here) · `networks.ts` checks use a 50 m grid index (`gridIndex`) — keep it, they run on every edit
- `infill.ts` fits a rule-compliant building to a generated plot (housing type from density) · `zoning.ts` development-control compliance · `networks.ts` utility network checks · `masterplan.ts` wizard generator
- `persist.ts` IndexedDB, recovery slot, project files on disk (File System Access handle linked per project; Save rewrites it), GeoJSON import core (`importFeatureCollection` + classifier) · `formats.ts` KML/SHP/CSV/DXF/OSM
- `report.ts` HTML planning report · `print.ts` print layout
- `store.ts` single Zustand store; undo tracks only `features` + `layers`; `layerForFeature`, `makeFeature`, `replaceFeatures` (one undo step)
- `map/MapCanvas.tsx` MapLibre render + Terra Draw (holds only the feature being edited) · `map/models3d.ts` Three.js custom layer (models at zoom ≥16; rebuilds only while visible — zoomed out or with the 3D view open an edit just marks it stale)
- `three/` 3D view (scene.ts is pure + tested) · both 3D views show `nearCentre(features, meta.center)` (20 km `SCENE_REACH`), never the whole project (far-apart sites made a 555 km scene); CityView orbit: `maxDistance` 3× scene radius, `zoomToCursor`, target clamped to 1.2× radius · point models (hydrants…) are shared templates drawn through the building batch · `three/buildings/` per-type building recipes (western/gulf) → `buildingModel` (merged per material, `details` group) · `three/batch.ts` draws all buildings as one merged mesh per material (per-building groups stay hidden as pick/edit copies; selection shows the group and zeroes its vertex range in the merge; not BatchedMesh — ANGLE/D3D11 emulates multi-draw) · `three/kit.ts` building parts · `three/facades.ts` generated façade textures · `three/models.ts` area details + street furniture · `three/thumbs.ts` library thumbnails · `three/edit3d.ts` 3D editing helpers (drag-move preview → `moveFeatures`, ring → `rotateFeatures`, library drop, compass); scene objects carry `userData.owner` = feature id · `three/night.ts` `darkness`/`litShare` curves; façade `NIGHT` uniforms (`setFacadeNight`), lamp pools and fleet beams all driven by `BuiltScene.setNight` (CityView `placeSun`; reset to day on unmount) · `three/cars.ts` procedural vehicles (instanced, shared materials+geometry) · `three/drive.ts` road graph + seeded car sim (lane-following, give-way junction boxes, traffic lights where ≥3 arms meet and ≥2 are non-local — `signalAt`, each arm 20 s green/3 s amber/2 s all-red in turn, the box streams one lane at a time; demand by hour; release valve, not counting time queued at a light, `Traffic.dropped`), stepped by `BuiltScene.traffic.step` · `three/pipes.ts` Underground view: pipe tubes per network with a flow-pulse shader patch (uniforms only per frame), manhole shafts, `ghost()` cached transparent copies; `BuiltScene.setUnderground` builds pipes on first use, hides instanced clutter, ghosts the rest (+ CityView's terrain); plain lines are merged per colour (one draw call per colour) · `three/signals.ts` instanced signal heads (driver-side kerb, lamps recoloured on phase change by `traffic.step`); CityView clock = Play/Pause + ×1/×60/×600/×3600 (`advanceHour` in `sun.ts`, hour kept in `hourRef`) · `three/traffic.ts` car placement + `laneLayout` (the one lane layout shared by cars and road markings; driving side `settings.drivingSide`)
- `ui/` panels & dialogs (`ToolRail` = labelled drawing tools left of the map, in Toolbar.tsx); `App.tsx` layout, autosave, shortcuts, `saveCurrent` (IndexedDB, then server best-effort)
- `api.ts` backend client (`/api`, Vite-proxied to host :8001 — 8000 is taken on this machine); everything degrades to IndexedDB-only when it's down
- `backend/` FastAPI (`app/main.py`), PostGIS (`app/db.py`: project JSON + features mirror, validity report), GDAL (`app/gdal_ops.py`: OGR vector → WGS 84, DEM → contours, GeoJSON → GeoPackage per layer in EPSG CRS); root `docker-compose.yml`, API bound to localhost (no auth yet)

## Conventions
- Store is the single source of truth; derived things (road surfaces, compliance, networks) are computed + memoised on the immutable `features` object, never stored.
- Coordinates WGS 84; metric work in `frame(origin)` (equirectangular); angles = degrees clockwise from east. `frame()` metres are NOT MapLibre's (110 574 vs ≈111 195 m per degree north): anything placed on the map from frame metres goes through `frameToMercator` (geo.ts), never `meterInMercatorCoordinateUnits` (that put the 3D overlay ~30 m off 5 km from its origin).
- Never fake features: unbuilt items show as "planned"/"needs backend". Generated layouts are labelled preliminary.
- Plots re-validate on every change (`attrs.issue`, '' = valid). Rules in `meta.settings`.
- Ponytail style: minimal code, reuse helpers, `ponytail:` comments mark known ceilings. Each new module gets a test file.

## Gotchas
- Terra Draw (2D editing) refuses coordinates with > 9 decimals ('excessive precision'); turf maths (rotate/scale, some wizard output) gives ~15. MapCanvas hands it `roundGeometry(…)` (geo.ts) and compares rounded geometry on commit — keep both, or rotated/generated features silently stop being editable.
- MapLibre 6 worker must be bundled explicitly (`?worker&url` in MapCanvas) — don't remove.
- Terrain: everything on the ground samples `terrainGrid().at` (the rendered mesh triangles), and draped surfaces go through `conformSurface` (cut along those triangles) — never sample raw elevation for things that must sit on the visible ground.
- Rebuilds are cheap only through caches in scene.ts: building models per feature object (`cachedModel`, WeakMap; template geometry `userData.shared`), and `memoOnFeatures` (LRU of 4, feature identity + key) for parked cars and lane markings — keep features immutable (replace, never mutate) or they go stale.
- Building materials are SHARED (cached in facades/kit, `userData.shared`): never mutate or dispose them; selection swaps in highlighted copies (scene.ts `litOf`).
- Use `style.load`, not `load` (waits for all tiles). CARTO tiles need keys — OSM, plus optional Google basemaps via the user's own Map Tiles API key (`map/google.ts`, localStorage only; never scrape mt*.google.com).
- Box zoom disabled (shift = multi-select). App shortcuts ignored while 3D walk has pointer lock.
- Browser testing: save before editing code (Vite reload is blocked by the beforeunload prompt → page looks hung); use dev globals `__store` / `__map` / `__view` / `__draw` (Terra Draw) (3D camera, orbit, renderer, built scene) (dynamic `import()` from devtools gets a different module instance); `TaskStop` leaves `node vite.js` alive on port 5317 — kill via PowerShell `Get-CimInstance` filtered on `cityandtownplanning` (leave `D:\QGISSYSTEM` alone); screenshots are scaled vs CSS px.
- After editing `three/` modules reload the tab fully (mark the project saved first: `__store.getState().markSaved()` skips the beforeunload prompt) — a long-lived page can keep a stale module instance.
- Bash heredocs with apostrophes break: write patch scripts to the scratchpad and run them.
